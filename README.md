No-frills configurations for Arch Linux on an IdeaPad.

## Dependencies
#### Core/Required
- networkmanager
- wireplumber
- pacman-contrib
- libnotify
- dunst
- xbindkeys
- zsh
#### (Optional)
- neovim
- kitty
- yazi
- zathura
- fastfetch

## Installation
> note: the installation script will overwrite any existing configurations on the system

install using the included install script:
```
chmod +x install.sh && ./install.sh
```
or manually install dependencies and link the corresponding dot/configuration files.
