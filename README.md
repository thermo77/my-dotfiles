No-frills configurations for Arch Linux on an IdeaPad.

## Dependencies
#### Core/Required
- nmcli
- pacman-contrib
- libnotify
- dunst
- xbindkeys
- zsh
#### (Optional)
- nvim
- alacritty
- fastfetch

## Installation
install using the included install script:
```
chmod +x install.sh && ./install.sh
```
or manually dependencies and link the corresponding dot/configuration files.
